# V21.3 — Need to Know Podcast Integration (Batch 4)

Content-only production ingestion of Need to Know Episodes #17–21 using the validated V21 workflow. The release adds five complete episode records, twenty source-grounded principal claims, five publication timeline events, and focused relationships to existing canonical people, organizations, cases, documents, and topics.

Episode #20 is the official 7NEWS Spotlight special edition produced with Need to Know. It is represented by the direct official 7NEWS video because no separate numbered Stellar Productions upload exists for that release.

Every episode uses its direct official video as the primary media reference. The official Need to Know YouTube collection remains the secondary reference.

No architecture, schema, rendering, template, navigation, routing, UI, styling, or knowledge-graph engine changes were made.
