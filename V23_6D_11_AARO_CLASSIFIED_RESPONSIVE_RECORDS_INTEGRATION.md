# V23.6D.11 — AARO Classified Responsive Records + Congressional UAP/USO Case Provenance Integration

This release implements the approved Objectives 1–26 on the V23.6D.10 base.

It adds a Current / non-Landmark Latest UAP News record, a permanent Research Library government-document record, five bounded source-attributed incident records, six structured claims, and bidirectional graph connections to the existing AARO, congressional oversight, PURSUE, disclosure and government-transparency knowledge domains.

The release preserves the controlling distinction:

> Acknowledgment that responsive records exist does not authenticate the reported incidents, and classification does not establish what the withheld records contain.

The lifecycle principle remains:

> **News can age; knowledge does not.**
